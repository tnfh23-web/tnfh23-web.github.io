# PROJECT background artwork

Generated with the built-in `image_gen` tool. Each scene is separate atmospheric artwork; real website thumbnails were not generated or repainted. Original generated images were converted to WebP (quality 88) with 960px mobile variants (quality 84). See `manifest.json` for dimensions and sizes.

## Shared prompt

```text
Use case: stylized-concept / cinematic photographic website backdrop.
Create ONE landscape 16:9 background image for the {NAME} project card in a web publisher portfolio.
{SCENE}
This is a separate FULL-BLEED atmospheric background behind an existing real website screenshot and text. Do NOT generate any website UI, screenshot, mockup, screen, device, browser window, text, letters, numbers, brand logo, watermark or frame. The foreground screenshot will be added by HTML. Keep the central 65 percent broad, low-detail and visually quiet. Concentrate recognizable environmental detail at the extreme edges. The lower quarter should be naturally dark and calm enough for white portfolio copy. A photographic designed scene with believable material and spatial depth, never a plain gradient or abstract blurry blob. Avoid a dominant focal subject competing with the real screenshot. Match a polished editorial portfolio, rich but restrained, gentle film grain, no artificial glows. Render only the background artwork, filling the entire image.
```
